# Map Blender files

Low-poly kit and layouts (ART_BIBLE section 1, MAP_PLAN).

- `clash_stand.blend` / `clash_stand.fbx`: the Clash Stand and octagon pen
- `kit_<zone>.blend`: modular pieces for a zone
- `layout_<zone>.blend` / `layout_<zone>_chunk<N>.fbx`: assembled layout, exported in chunks
- `palette.png`: the shared 256x256 colour palette texture
