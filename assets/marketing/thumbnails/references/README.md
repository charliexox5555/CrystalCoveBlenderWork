# Style references: Ball VS Ball (outside game, for style only)

Ball VS Ball is a top Roblox game whose thumbnails and icon do well. Glass Clash's design already cites it
(GAME_DESIGN pillar 3). These images show ChatGPT the **energy and composition** to aim for. Never copy
their content: no smiley ball, no web ball, no claw, no candy bucket, no fonts and no UI from them.

## What wins, in short

1. **One focal point, very big.** The hero object fills 40–60% of the frame and is close to camera, slightly low angle.
2. **A rival in depth** (smaller, opposite side) so the image reads "versus" at a glance.
3. **Motion you can see:** speed streaks, blur trails, flying debris.
4. **Clean backgrounds:** simple sky gradient and plain floor; nothing busy behind the hero.
5. **Saturated colour, glossy highlights, strong rim light**, and big shapes that read at 300 px.
6. **Emotion:** faces and avatar poses (grin, shock, cheer, fear).
7. **Seasonal versions are recolours of a winner**, not new designs.

Glass Clash rules still win over the references: show only real Glass Clash glassies, stand, islands and avatars;
no text or logo; kid-friendly.
