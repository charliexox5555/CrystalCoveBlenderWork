# Marketing plan

- **Before launch (from M1):** post short clips of the best shatters (TikTok, Shorts, Reels). Start a Discord and Roblox group.
- **Bracket videos:** render "16 glassies, only one survives" videos in Blender with the real game models (real-life format + fantasy glassies). End card: play on Roblox.
- **Launch (M6):** cross-promote from the existing 150-CCU game (billboard/portal + group shout), launch codes, first tournament event.
- **Icon/thumbnail:** a fantasy glassy (sword or unicorn) mid-shatter, bright, readable at small size. A/B test.
- **Ads:** only after D1 retention is healthy.
- **Seasonal:** winter (snow globes, ornaments), Valentine's, Halloween 2027 (Pumpkin Patch).
- **Community:** vote on the next glassy in Discord every update.
